Codelists, DSDs and metadata.

7. Search procedure before creating a new code
----------------------------------------------
Step 1  Search the SDMX Global Registry.
Step 2  Search the relevant classification custodian.
Step 3  Search existing international SDMX structures in the same domain.
Step 4  Search relevant regional standards.
Step 5  Search the source institution's published classifications/codebooks.
Step 6  Compare definitions/scopes, not only labels/codes.
Step 7  Record why candidates were accepted or rejected.
Step 8  Create a new local code only when no adequate equivalent exists.
